# Interview Talking Points

## 1. Project Summary

I built an Azure lakehouse modernization project that demonstrates ADF ingestion, ADLS medallion storage, Synapse PySpark transformations, Synapse SQL serving, and a Fabric migration path.

## 2. Why This Project Matters

Many companies are not fully on Fabric yet. They still use ADF, ADLS, and Synapse, but they need engineers who understand how to support the current platform while preparing for modernization.

## 3. Technical Strengths Demonstrated

- Parameterized ADF pipelines
- Reusable ingestion patterns
- PySpark transformation logic
- Data quality validation
- Quarantine handling
- SQL serving layer
- Fabric-ready architecture

## 4. Strong Interview Line

> This project shows that I understand both the current Azure data engineering stack and the direction Microsoft data platforms are moving with Fabric.
